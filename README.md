# QuickBite – Food Delivery Management System

A database-driven Food Delivery Management System developed using Oracle Database, Node.js, Express.js, and HTML/CSS/JavaScript.

## Features

* Customer, Delivery, and Admin roles
* User authentication
* Food order management
* Delivery management
* Oracle database integration
* REST API backend
* Role-based access control

## Technologies

Frontend: HTML, CSS, JavaScript
Backend: Node.js, Express.js
Database: Oracle SQL
Authentication: JWT, bcrypt
Tools: VS Code, Git, GitHub

### 1. Clone the repository

bash

cd Project

### 2. Install dependencies

bash
cd backend
npm install

### 3. Configure Oracle Database

Run the SQL files:

database/schema.sql
grant.sql

### 4. Start the backend

bash
node server.js
